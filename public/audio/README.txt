WEDDING MUSIC SETUP

The website's music player expects this file:
  public/audio/wedding-shehnai.mp3

To add a traditional shehnai wedding track:
1. Download the track "Traditional wedding_ceremonial vibe with shehna" from Pixabay:
   https://pixabay.com/music/wedding-traditional-wedding-ceremonial-vibe-with-shehna-376293/
2. Check the current Pixabay Content License and download the MP3.
3. Rename the downloaded file to: wedding-shehnai.mp3
4. Place it in this folder (public/audio/).
5. Run npm run dev and click "Open Your Invitation" or the "Wedding Music" control.

The player is set to loop. Audio playback begins only after a guest interacts with the page because browsers restrict autoplay.
